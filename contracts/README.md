JSON Schema files in this directory are the language-neutral v0.1-draft-frozen
contracts. `additionalProperties` is false on envelope objects. Profile payload
is governed by `profiles/xuanhuan-gameplay-scene-v1/profile.schema.json`.

`CollectionDecision` and `CollectionReview` are additive collection-quality
sidecars. They do not contain FactClaim and do not change export assurance.
