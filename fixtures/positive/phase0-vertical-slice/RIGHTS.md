# Rights declaration for the Phase 0 vertical-slice fixture

`novel.txt` is an original, entirely fictional test work created for this
repository. It is released under the Creative Commons CC0 1.0 Universal public
domain dedication.

The complete work is the UTF-8 byte sequence in `novel.txt`; there are no omitted
chapters. The repository and its automated tests may store the full text, send it
to a semantic executor, and export excerpts. `preparation-input.json` records that
authorization independently from technical access and source-quality declarations.

are exploration metadata only and are not evidence that any scene occurred.
