# Observation research CLI acceptance slice

Run `scripts/observation_research_wheel_smoke.py` with an installed interpreter.
It copies these inputs to a fresh output directory, seals the research records,
records simulated search and source operations, prepares a source-only Generic
Handoff, answers native agent-file tasks from the fixed oracle, resumes execution,
and validates exact receipts and research reports in fresh child processes.

The geography and race cases each contain a supported nonempty observation; a
separate complete work covers successful zero-record extraction. Every semantic
assurance remains UNQUALIFIED. This is an integration fixture, not a semantic
benchmark, automatic browser search, or a second extraction implementation.
