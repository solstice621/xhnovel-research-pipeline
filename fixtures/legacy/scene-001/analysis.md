# analysis — SCENE-2026-08-29-001「三年之约」结构分析(PILOT)

- 输入:scene-facts.md(仅引用其断言;下文括注分级)+ context-snapshot.md(本阶段注入的项目上下文)
- 性质:本文件是 Design Analyst 阶段产物;所有设计判断均为 **Agent 提案**,不是原作事实,也不是项目决策
- 研究问题:RQ-001 能力暴露应该产生什么有限信息?

## 1. 玩家体验:什么值得让玩家亲自决定

若玩家处于萧炎位置,这个桥段里真正的玩家决策不是"打赢比试",而是一串**信息代价决策**:

- 是否公开使用底牌能力(异火)——用了赢得干脆,但当众暴露"我拥有异火"这件事,并冒着被特定在场者关联出伪装身份的风险(SceneFacts §4:施展异火当场暴露岩枭身份,SUPPORTED);
- 是否把比试规则改成"生死各安天命"——提高风险换取彻底了结的机会(§3,SUPPORTED);
- 战后是否阻止对手自尽、是否当众烧掉休书——即时人道/关系决策,直接改变与败者及其宗门的后续关系(§3,CONFIRMED);
- 暴露身份后如何脱身——决斗胜利不结算处境,反而制造了新处境(§5,SUPPORTED)。

**体验假设(未验证):**这个桥段的可玩内核是"每次使用能力都是一次出价":玩家清楚自己让世界看见了什么,并预判谁会因此重新评估自己。若能力使用没有信息代价,该桥段退化为数值比大小。

## 2. 因果:这个体验成立,世界必须客观支持什么

从 SceneFacts 反推,原作结构依赖以下客观事实链(每条都能落到状态/事件/查询):

1. 角色拥有**未公开的持久能力状态**(异火),且"拥有"与"他人是否知道拥有"是两个独立事实(§2:嫣然战前不知萧炎是岩枭,CONFIRMED);
2. 决斗是**有观察者集合的公开事件**(§2/§3:无数弟子观战、云棱主持,SUPPORTED/INFERRED);
3. 能力使用产生**可观察特征**(异火可被在场者辨识为异火,§4,SUPPORTED);
4. **跨事件身份关联需要特定证人**:把"眼前用异火者"关联到"墨家神秘人/岩枭"的,是唯一亲历过两个事件的葛叶(§4,SUPPORTED);无既往记忆的普通弟子只更新出"他有异火、他很强"(§4,INFERRED);
5. 认知更新驱动**各自动机下的行为变化**:云棱借声誉受损发难留人(§4,SUPPORTED)、嫣然评价与情感转变并决定入生死门(§5,SUPPORTED)、云山被冲突升级引出(§5,SUPPORTED);
6. **信息传播有延迟与边界**:云山闭关多年不知情、萧炎"事后得知"萧家遇袭(§5,SUPPORTED)——没有任何断言显示不在场者即时获知决斗信息。

## 3. 有限认知:谁知道什么(本案例最有价值的部分)

决斗前的认知分布本身就是**分层且互不一致**的(§2):

| 主体 | 战前认知 | 战后增量 |
|---|---|---|
| 云岚宗普通弟子 | "废物/不自量力"(INFERRED) | 实力+拥有异火(INFERRED) |
| 云棱 | 已知"脱去废物之名",仍误估胜负(INFERRED) | 实力+异火+葛叶的指认(可利用的怀疑) |
| 纳兰嫣然 | 不知萧炎=岩枭(CONFIRMED) | 实力+异火+岩枭身份+由此而来的情伤(SUPPORTED) |
| 葛叶 | 知道"墨家神秘人"存在,不知是萧炎 | **关联判断**:眼前人=墨家神秘人(SUPPORTED) |
| 云山(不在场) | 无 | 延迟获知,经冲突升级才介入(SUPPORTED) |

**对 RQ-001 的提案级回答(单案例,待更多异质案例检验):**

> 一次公开能力使用暴露的不是"真实实力值",而是:`事件的可观察特征 × 实际观察者集合 × 每个观察者的既往认知`所产生的**逐观察者信息增量**。同一事件让弟子得到"他有异火",让葛叶得到"他就是墨家那个人"——增量差异完全由既往认知差异产生,不需要任何专门的"暴露等级"数值。

## 4. NPC 自主:原作是否依赖 NPC 必须做某事

不依赖。链条上每个 NPC 行为都有自身动机支撑:云棱发难是为宗门声誉(SUPPORTED)、嫣然自刎是"不辱宗门名声同时履行约定"(CONFIRMED)、云山介入是宗门冲突升级(SUPPORTED)。没有一步需要导演替 NPC 作答;移除任何一个 NPC 的自主选择(如云棱选择不发难),后续链条自然分叉而非崩坏。

## 5. 反事实(Agent 推演,非原作事实)

- **不用异火、只用玄重尺获胜**:实力认知照常更新,但异火与岩枭关联不发生,葛叶无从指认,云棱失去最顺手的借口——"暴露什么"取决于**使用了哪个具体手段**,而不是"胜利"这个结果本身;
- **葛叶不在场**:异火照样被全场看见,但跨事件关联无人能做,岩枭身份可能保住——关联依赖特定证人在场,这是可被玩家侦察和利用的结构;
- **玩家不阻止自刎**:赌约与人命的后果链分叉,云岚宗的敌意结构完全不同——战后即时决策有持久分量;
- **玩家根本不赴约**:约定的社会后果如何结算,原作材料未覆盖(§7 UNKNOWN)——这是承诺结构问题,路由给 RQ-003。

## 6. 持久后果:世界之后必须记住什么

- "萧炎拥有异火"从私密事实变为(在场者范围内的)公开知识;
- "萧炎=岩枭"进入特定 NPC(葛叶、云棱、嫣然)的认知;
- 云岚宗—萧炎的组织级敌对立场("不死不休"是宗主身份的公开宣告,SUPPORTED);
- 休书烧毁=婚约恩怨了结的社会事实(CONFIRMED);
- 嫣然的评价、情感与人生路径改变(生死门,SUPPORTED)。

## 7. 重组:这些结构还能组合出什么原作没有的玩法(Agent 提案)

- 玩家**主动管理暴露**:选择在何时、何地、当着谁的面使用哪个手段——"当着谁"成为战术变量;
- 玩家经营**伪装双身份**,并侦察"哪些 NPC 同时见过我的两个身份的标志性特征",提前规避或清除关联证人;
- 反向玩法:玩家作为观察者,凭 NPC 当众使用的能力特征回溯其隐藏身份;
- NPC 侧对称:强敌也可能一直隐藏底牌,玩家对其实力的认知条目同样可错——嫣然战前的误估(CONFIRMED)证明该结构天然双向。
