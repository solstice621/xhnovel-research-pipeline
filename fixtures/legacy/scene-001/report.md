# report — SCENE-2026-08-29-001「三年之约」(PILOT)

## 结论

针对 RQ-001「能力暴露应该产生什么有限信息」,第一个互联网案例(《斗破苍穹》三年之约决斗)给出的提案级答案是:**暴露产生的信息 = 事件可观察特征 × 实际观察者集合 × 每个观察者的既往认知**。同一次异火使用,让普通弟子只得到"他有异火、他很强",让亲历过墨家事件的葛叶得到"他就是岩枭",让不在场的云山什么也没得到(直到冲突升级把他引出来)。原作没有任何"实力值全局公开"的痕迹;暴露甚至可以只是**可利用的怀疑**而非确证。

对项目更重要的是映射结果:七条结构元素中四条(能力/认知分离、观察者投影、刺激重评、反差体验)由现有设计直接或同构承载——**这个最经典的"扮猪吃虎"桥段不需要任何"打脸系统"**。真正缺口只有两个具体子问题:(a) 能力使用事件的可观察特征粒度(观察者看见"火"还是"异火"还是"哪种异火");(b) 特定证人由既往认知产生派生关联的通用表达(项目已有 `observer_identifies_source` 单点先例)。另有两项(组织级立场、跨场景传播)超出当前范围,只挂图。
